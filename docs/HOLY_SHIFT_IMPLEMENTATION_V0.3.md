# Holy Shift v0.3 实现基线

## 可玩交付范围

本版是第一章完整纵向切片，不伪装为全岛开放世界。玩家能在神圣广场、圣水池、礼拜集合区与私募教堂入口连续移动、调查、战斗，并完成“圣水变生水”的事件闭环。

主线状态：

1. 与牧司学姐确认异常。
2. 调查圣水池。
3. 在广场中实时清除三只“生水泡影”。
4. 向 Pingu 核对供应链备案，发现被移走的“圣”字痕迹。
5. 向林镇阴确认旧案。
6. 在圣水池旁实时击败“已审批水鬼”。
7. 使用 Holy Shift 把“圣”移回圣水。
8. 前往私募教堂入口，见证电梯显示 `191F / SHIFT`。

## 输入

- `W A S D`：移动
- `Shift`：疾跑；每次按下恢复 8 点 SHIFT
- `Space`：跳跃
- `Ctrl + Shift + W A S D`：沿当前视角三维飞行；俯视时转为滑翔并恢复耐力
- 鼠标：观察
- 鼠标左键 / `J`：三段手杖连击
- 鼠标右键 / `Q`：16.5 米大范围高伤 Holy Shift，消耗 40 SHIFT
- 单按 `Ctrl`：闪避
- `E`：调查 / 交谈
- `B`：打开 / 关闭背包，使用食品
- `V`：第一 / 第三人称
- `R`：返回最近安全点
- `Esc`：暂停

## 代码与资产分层

- `src/art/materials`：共享色板与材质
- `src/art/modeling`：建模原语、曲线、拱券、饰条与性能工具
- `src/art/characters/<character>`：每名角色独立模型与动画
- `src/art/enemies`：异常敌人模型
- `src/art/architecture`：教堂、圣水池、广场与城市天际线
- `src/art/props`：公告牌、长椅、路灯、红肠补给车等可见道具
- `src/gameplay/combat`：场景内实时战斗、判定、受击与敌人 AI
- `src/gameplay/quests`：第一章状态机与剧情数据
- `src/domain/economy.ts`：码货币、购买、背包消耗与临时耐力上限规则
- `src/world`：资产拼装、碰撞、交互与环境更新
- `src/ui`：不遮挡视野的 HUD、对话、食品商店、背包与设置

## Pingu 食品循环

- 每次主线进度推进只结算一次 `91 码`；结算键写入存档事件账本，重复交谈不能刷取。
- 旧版 v4 存档按当前主线位置追溯补发已完成节点的码，并同步写入同一事件账本；已消费余额不会在后续读取时重复补发。
- Pingu 摊位始终可交互，目前只出售食品，不实现物品、贿赂或真实支付。
- 红肠售价 `18 码`，临时增加 `27.8` 耐力上限。
- 忘情牛肉面售价 `27.8 码`，临时增加 `91` 耐力上限。
- 成吉思鸡售价 `200 码`，临时增加 `278` 耐力上限。
- 购买后明确选择“立即使用”或“放入背包”；`B` 打开背包并可使用库存。
- 同时只保留一个食品增益；食用另一食品会替换当前增益。
- 增益期间最大耐力为 `100 + 食品加成`；当前耐力真正归零时立即清除增益，最大耐力恢复为 `100`。
- 金额以一位小数归一，所有商品 ID 都通过固定目录白名单验证。

## 性能预算

- 共享材质与几何；重复窗、铺装、栏杆和灯具使用实例化。
- 战斗敌人按章节状态创建或休眠，不在后台持续执行 AI。
- 默认关闭动态阴影，以烘焙感顶点色、接触阴影片和环境光层次替代。
- 自动画质根据 P95 帧耗时调整渲染比例。
- 动画与 AI 使用有上限的 `delta`，防止后台切回时穿透或瞬杀。
- 广场群众以职业分组顶点色合批；软件渲染器隐藏远景组并简化近景组。

## 碰撞与防卡死门槛

- 玩家胶囊不能生成在实体碰撞体内。
- 低帧率疾跑、闪避和击退必须分步移动，避免穿墙。
- 每个主线交互物必须存在至少一个有地面、无碰撞、可直达的交互环。
- Pingu 摊位营业侧拥有独立交互锚点与安全环，不与 Pingu 剧情交互争抢。
- 凹角采用滑墙移动；摄像机使用射线回缩避免穿建筑。
- 越界、掉落、非有限坐标或实体重叠会自动回到安全点。
- 飞行和滑翔均使用三维子步进、22 米高度上限和独立岛界；不能穿建筑或从高空越过边界。
- 俯视滑翔采用受控下降、墙面滑动和安全落点搜索；滑翔期间停止飞行消耗并恢复耐力。
- 圣水池南侧设置可见入口台阶，池底为独立落脚面；进入水体后持续恢复生命与 SHIFT。
- 自动网格扫描覆盖广场边缘、喷泉环、教堂立面、公告牌、灯柱与所有主线目标。
