# Holy Shift v0.3 实现基线

## 可玩交付范围

本版是第一章完整纵向切片，不伪装为全岛开放世界。玩家能在神圣广场、圣水池、礼拜集合区与私募教堂入口连续移动、调查、战斗，并完成“圣水变生水”的事件闭环。

主线状态：

1. 与牧司学姐确认异常。
2. 调查圣水池。
3. 在广场中实时清除三只“生水泡影”。
4. 向 Pingu 核对供应链备案，发现被移走的“圣”字痕迹。
5. 向林镇阴确认旧案。
6. 在圣水池旁实时击败“已审批水鬼”。
7. 使用 Holy Shift 把“圣”移回圣水。
8. 前往私募教堂入口，见证电梯显示 `191F / SHIFT`。

## 输入

- `W A S D`：移动
- `Shift`：疾跑
- `Space`：跳跃
- `Ctrl + Shift + W A S D`：沿当前视角三维飞行，持续消耗耐力
- 鼠标：观察
- 鼠标左键 / `J`：三段手杖连击
- 鼠标右键 / `Q`：Holy Shift
- 单按 `Ctrl`：闪避
- `E`：调查 / 交谈
- `V`：第一 / 第三人称
- `R`：返回最近安全点
- `Esc`：暂停

## 代码与资产分层

- `src/art/materials`：共享色板与材质
- `src/art/modeling`：建模原语、曲线、拱券、饰条与性能工具
- `src/art/characters/<character>`：每名角色独立模型与动画
- `src/art/enemies`：异常敌人模型
- `src/art/architecture`：教堂、圣水池、广场与城市天际线
- `src/art/props`：公告牌、长椅、路灯、红肠补给车等可见道具
- `src/gameplay/combat`：场景内实时战斗、判定、受击与敌人 AI
- `src/gameplay/quests`：第一章状态机与剧情数据
- `src/world`：资产拼装、碰撞、交互与环境更新
- `src/ui`：不遮挡视野的 HUD、对话与设置

## 性能预算

- 共享材质与几何；重复窗、铺装、栏杆和灯具使用实例化。
- 战斗敌人按章节状态创建或休眠，不在后台持续执行 AI。
- 默认关闭动态阴影，以烘焙感顶点色、接触阴影片和环境光层次替代。
- 自动画质根据 P95 帧耗时调整渲染比例。
- 动画与 AI 使用有上限的 `delta`，防止后台切回时穿透或瞬杀。
- 广场群众以职业分组顶点色合批；软件渲染器隐藏远景组并简化近景组。

## 碰撞与防卡死门槛

- 玩家胶囊不能生成在实体碰撞体内。
- 低帧率疾跑、闪避和击退必须分步移动，避免穿墙。
- 每个主线交互物必须存在至少一个有地面、无碰撞、可直达的交互环。
- 凹角采用滑墙移动；摄像机使用射线回缩避免穿建筑。
- 越界、掉落、非有限坐标或实体重叠会自动回到安全点。
- 飞行使用三维子步进、22 米高度上限和独立岛界；不能穿建筑或从高空越过边界。
- 圣水池南侧设置可见入口台阶，池底为独立落脚面；进入水体后持续恢复生命。
- 自动网格扫描覆盖广场边缘、喷泉环、教堂立面、公告牌、灯柱与所有主线目标。
