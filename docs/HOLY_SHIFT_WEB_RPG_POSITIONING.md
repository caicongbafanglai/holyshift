# Holy Shift：Web RPG 定位与功能清单

## 产品定位

Holy Shift 是一款以“神圣力量/世界变化”为主题的轻量 Web RPG。玩家通过任务、战斗、装备和角色成长，逐步揭开世界的秘密。

## 竞品对标

- **主对标：《暗黑破坏神》系列**：参考刷宝、战斗和角色成长体系，但采用轻量化 Web 体验。
- **交互参考：《炉石传说》**：参考网页端操作便捷、界面清晰和短时游玩节奏。
- **包装参考：《原神》**：参考角色塑造、世界观表达和剧情包装。

## 核心循环

创建角色 → 主城接取任务 → 探索地图 → 战斗 → 获取装备/资源 → 角色成长 → 解锁区域与剧情。

## P0：核心功能

- Web 登录、账号管理、角色创建
- 职业、属性、技能体系
- 主城、地图、关卡和副本
- 回合制或即时战斗系统
- 普通敌人、精英敌人和 Boss
- 装备掉落、穿戴、强化、分解
- 经验、等级和技能升级
- 主线任务、支线任务和成就
- NPC 对话、剧情文本和任务追踪
- 背包、仓库和角色面板
- 自动存档、断线重连和数据恢复
- PC/移动端网页适配
- 新手教程、战斗提示和错误反馈

## P1：扩展功能

- 多职业和角色外观
- 公会、好友和排行榜
- 组队副本或异步合作
- PvP 竞技场
- 赛季、每日任务和限时活动
- 装备套装、符文和天赋树
- 商城与纯外观付费

## 暂不建议加入

- 一开始制作开放世界
- 复杂实时多人战斗
- 过多职业和装备词条
- 抽卡、强制付费和复杂经济系统
