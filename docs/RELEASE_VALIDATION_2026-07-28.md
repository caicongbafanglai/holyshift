## 3. 穿模、墙角与防卡死专项

- 所有章节检查点均验证为有限坐标、正确落地且不在实体碰撞体内。
- 所有主线对象与 Pingu 摊位营业侧均存在有地面、无障碍、可进入交互距离的安全环。
- 三只泡影与已审批水鬼的出生点均无重叠并保持安全间距。
- 低帧率疾跑采用固定水平子步进，薄墙测试没有一步穿透。
- 斜向挤压硬墙角时，受阻轴停止、可行轴继续滑动。
- 对喷泉、教堂立面、公告牌、长椅、灯柱、签到机、补给车和岛屿边界执行 `600+` 条确定性扫掠路线。
- 在 1/10/21 米高度对多方向俯仰飞行执行 `240+` 组三维障碍与岛界扫掠。
- 滑翔沿水平视向推进并以受控速度下降，继续执行墙面阻挡、轴向滑动、岛界和安全落点检查。
- 从 NPC、盆壁和低矮道具上方解除飞行时，下降会穿过顶部代理体并搜索最近无碰撞落点，不会悬停或落进角色身体。
- 运行时周期检查越界、坠落、非有限坐标与实体重叠；异常状态会回到当前章节安全点。
- 第三人称相机使用场景射线回缩；第一人称隐藏玩家身体，切换不改变玩家位置。
- 生产包不包含穿墙或垂直调试入口；正式飞行始终受耐力、三维碰撞与安全域控制。

## 4. 性能与资源

- 高细节程序化场景约 `147k` 可见三角形、少于 `100` 次绘制调用；新增六名群众按近/远景分组合批。
- 软件/隐私 GPU 名称无法可靠识别时，持续慢帧会触发行为检测降级，而非只依赖 GPU 字符串。
- 流畅优先档切换为轻量铺地、隐藏远景实例、简化静态/刚性网格、关闭接触阴影并使用 Lambert 光照材质。
- WebKit 软件档实测约 `49k` 可见三角形、约 `70` 次绘制调用、`0.5` 内部 3D 像素比；DOM UI 保持原生清晰度。
- 软件 WebKit 的预热后直接渲染 gate 为 `<25 ms`，世界更新约 `0.17 ms`。
- 生产 JS gzip 约 `212 kB`，CSS gzip 约 `5.5 kB`，无外部运行时模型、贴图、字体、脚本或音频请求。
- 默认关闭实时阴影与后处理；重复铺装、窗格、栏杆和家具使用实例化或静态批处理。

## 5. 安全与数据边界

- 无账号、支付、广告、分析埋点、第三方 CDN 或远端运行时代码。
- 动态 UI 文本使用 `textContent`；两处 `innerHTML` 只创建固定本地模板。
- CSP 禁止外部脚本、对象、表单与跨站框架；Nginx 追加 `nosniff`、`DENY` frame、`no-referrer` 与权限策略。
- E2E 流程桥同时要求回环主机与 `?e2e=1`，生产域名不会暴露。
- 依赖由 `package-lock.json` 固定；运行时直接依赖只有 MIT 许可的 Three.js `0.185.1`。
- GitHub Actions 权限为 `contents: read`，第三方 Actions 固定到完整提交 SHA。
- `dev` CI 会执行 typecheck、lint、单测、构建、依赖审计及 Chromium/WebKit/Firefox 生产包 E2E。
