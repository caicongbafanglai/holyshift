# Holy Shift 1.0：3D 范围覆盖与实施决定

> 决定日期：`2026-07-27`
>
> 工作分支：`dev`
>
> 状态：`APPROVED-FOR-IMPLEMENTATION`
>
> 来源：项目负责人在当前开发线程中的明确指令

## 1. 决定

项目负责人明确要求立即按照需求文档制作可发布游戏，并把以下内容提升为 1.0 Must：

- 游戏表现改为 3D。
- 玩家可在标准第三人称 RPG 视角与第一人称视角之间即时切换。
- 探索采用键盘与鼠标驱动的自由移动。
- 流畅度高于非核心视觉复杂度。
- 穿模、狭窄角落卡死、台阶/边缘接缝、相机穿墙和安全复位属于重点发布阻断项。
- `https://qt.fengche.ai/holyshift` 必须能够在现代桌面浏览器中直接进入游戏。
- 操作说明必须简洁、常驻、可收起，且不能明显遮挡主要视野。

本决定覆盖 `docs/HOLY_SHIFT_WEB_RPG_POSITIONING.md` 中与上述内容冲突的 `DEC-01`、相关 Won't 条目和 2D 节点式表述。它同时构成第 12.2 节所述的 3D/自由移动范围重新打开决定。

## 2. 保留的核心产品承诺

以下内容不因 3D 化改变：

- 无安装、无账号、无支付、无广告、无分析埋点。
- 单人、单角色、简体中文、本地浏览器存档。
- 主线闭环仍为“圣堂任务 → 普通战 1 → 武器选择 → 普通战 2 → 圣物与成长选择 → Boss → 世界变化”。
- 战斗仍使用可见敌人意图、攻击/防御/圣术、信仰资源和确定性结算。
- 两场普通战和一场 Boss 战是不可删除的 Must。
- 两个装备槽、四件固定装备、两次装备选择与一次成长选择是不可删除的 Must。
- Boss 回归仍覆盖 8 种合法成长组合；纯普通攻击必须失败，每种组合必须存在同时使用防御和圣术的通关路径。
- 刷新恢复、战斗前安全检查点、坏档回退、设置、键鼠、减少动态效果、静音、性能、许可、测试与回滚要求继续有效。

## 3. 3D 实施边界

为满足流畅度优先，本版本采用下列约束：

- 使用低多边形、程序化材质和几何体，不下载高分辨率贴图或来源不明资产。
- 世界为一条紧凑主路径加一条可选侧路，不扩成开放世界。
- 探索为实时自由移动；战斗进入确定性回合制交互，不改成即时动作战斗。
- 不加入攀爬、游泳、载具、布料、刚体堆叠或破坏系统。
- 不加入移动端专项触控、多角色、多人、账号、云档、背包管理或随机词条。
- 第一人称与第三人称共用同一玩家胶囊体、交互距离和进度状态，不产生两套玩法规则。

## 4. 新增客观验收

### 4.1 相机与操作

- `V` 可在第一/第三人称之间切换，切换不改变玩家位置、朝向、任务或战斗状态。
- 鼠标锁定后控制视角；`Esc` 释放鼠标并打开暂停设置。
- 第三人称相机遇到实体遮挡时自动缩短距离，不应穿过墙体显示墙后空间。
- 第一人称不显示玩家身体遮挡画面，近裁剪面不得切穿常规交互对象。
- 常驻键位提示在 `1280×720` 与 `640×360` 下不遮挡准星、任务目标、战斗意图或关键按钮。

### 4.2 移动与碰撞

- 玩家使用半径不小于 `0.35 m`、高度约 `1.78 m` 的胶囊/圆柱近似碰撞体。
- 单帧水平位移必须分步处理，避免低帧率时穿过薄墙。
- 碰撞后允许沿未阻挡轴滑动，不能因斜向接触墙角而永久卡死。
- 可走台阶高度、最大坡度、地面检测、跳跃缓冲和坠落复位必须有冻结常量。
- 出生点、三个战斗点、两个奖励点、Boss 点和结局点均需验证无重叠碰撞。
- 每个主路径墙角、门框、柱间、侧路死角和地图边界必须执行持续挤压测试；不得进入碰撞体或形成无法通过 `R` 安全复位恢复的状态。
- 存档只记录已验证的安全检查点；读取到非法坐标时回退至最近检查点。

### 4.3 性能

- WebGL 渲染器请求高性能 GPU，默认关闭实时阴影和昂贵后处理。
- 渲染像素比设上限，并能根据持续帧时间降低渲染比例。
- 复用几何体/材质；重复装饰优先使用实例化网格。
- 生产构建的初始压缩传输目标不超过 `2.5 MB`。
- 参考机固定 60 秒探索场景的目标为 p95 帧时间 `≤ 33.3 ms`；连续 `10` 秒低于目标时自动降低画质并向玩家给出非阻断提示。

## 5. 验收优先级

发生冲突时按以下顺序处理：

1. 存档完整性、安全恢复和无软锁。
2. 玩家碰撞、相机碰撞、穿模和卡死。
3. 核心任务与确定性战斗闭环。
4. 帧时间、内存与加载体积。
5. 操作可读性、无障碍和反馈。
6. 视觉丰富度与可选内容。

本覆盖决定不把“对标市面游戏”解释为复制具体作品的角色、文本、地图、标志或资产。对标只用于交互清晰度、镜头手感、节奏、反馈和完成度标准。
