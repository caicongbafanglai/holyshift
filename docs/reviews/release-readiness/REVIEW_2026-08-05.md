## 本轮发布边界事故

本轮验证实际证明了“开发工作树就是线上目录”并非理论风险：`2026-08-05
23:31:22`，一个技术复查任务误执行默认 `npm run build`，未提交 bundle 被写入
工作树 `dist`；由于现网 Nginx 直接服务该目录，公网随即切到
`commit: unbound-local-build`。`23:36:31`，主审从锁定提交重新构建，并与
2026-07-28 留存产物逐文件 SHA-256 核对一致后，以可恢复目录切换还原基线。

因此本轮确实发生过“未审版本上线约五分钟、随后恢复基线”两次无审计内容切换；
不能再声称全过程未影响线上。当前公网内容已恢复 `ef10ef8` 基线，意外 bundle
已另行留存；本轮未改 live Nginx 或 Cloudflare 配置。该事故只有在现网迁移到
`/srv/holyshift/releases`、共享哈希资产库、权限隔离和受控部署后才算关闭。
